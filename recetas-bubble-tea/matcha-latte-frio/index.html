Matcha latte frío y versión hojicha

Puedes prepararlo con mezcla lista para un servicio rápido o con matcha puro para controlar la receta. La misma técnica sirve para un hojicha latte.

Ingredientes

  • Taiwan Matcha Insumos Pop (mezcla lista) o Shizuoka Matcha 100% puro (dosifica según intensidad deseada)
  • 200 ml de leche fría (entera o vegetal)
  • 60 ml de agua caliente (si usas matcha puro, para activar el té)
  • Endulzante al gusto (el matcha puro no viene endulzado)
  • Hielo

Preparación

  1. Si usas matcha puro: bátelo con el agua caliente (batidor de bambú o eléctrico) hasta que no queden grumos.
  2. Si usas la mezcla lista: disuélvela directamente en un poco de leche.
  3. Llena el vaso con hielo y vierte la leche fría.
  4. Corona vertiendo el matcha por encima para lograr el degradé verde.
  5. Opcional: termina con una capa de Cheese Foam.
Tip de barra: Cambia el matcha por Hojicha o Pure Hojicha para ofrecer una versión tostada con la misma técnica base.
